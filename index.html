File Launcher V2.4 🚀

Pardus üzerinde .exe ve .jar dosyalarını tek tıkla çalıştırın!

Proje Hakkında

Pardus Linux işletim sisteminde Windows (.exe) veya Java (.jar) uygulamalarını terminale kod yazmadan, doğrudan çift tıklayarak çalıştırmanızı sağlayan sürücü ve entegrasyon paketidir. Hem GNOME hem de XFCE masaüstü ortamlarını otomatik olarak destekler.

📥 Pardus İçin İndir (.deb)

Kolay Kurulum Kılavuzu 🛠️

Artık terminal komutlarıyla uğraşmanıza gerek yok!

  1. Yukarıdaki "Pardus İçin İndir (.deb)" butonuna basarak paketi indirin.
  2. İnen File_launcher_2.4.1_all.deb dosyasına çift tıklayın.
  3. Açılan Pardus Paket Kurucu penceresinde "Paketi Kur" butonuna basın ve şifrenizi girin.
  4. Sistem gerekli Python, Wine ve Java bağımlılıklarını otomatik olarak yükleyecektir.
  5. Kurulum bittiğinde herhangi bir .exe veya .jar dosyasına sağ tıklayıp File Launcher V2.4 ile açabilirsiniz!

Özellikler

  • Sıfır Terminal Kullanımı: Kurulumdan çalıştırmaya kadar hiçbir kod yazmanız gerekmez.
  • Çift Masaüstü Desteği: Hem Pardus GNOME hem de Pardus XFCE ile tam uyumludur.
  • Otomatik Motor Eşleme: Windows uygulamalarını Wine, Java uygulamalarını Java çalıştırma motoru ile otomatik bağlar.
